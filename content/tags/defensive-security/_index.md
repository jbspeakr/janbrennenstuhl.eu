Defensive security is a proactive approach to prevention, detection, and response to attacks. It is a subset of cybersecurity and the opposite of [offensive security]({{< ref "/tags/offensive-security/" >}} "Offensive Cyber Security"). Defensive cybersecurity aims to safeguard an organization and ensure security controls' effectiveness.

Following articles discuss defensive security measures, such as technical approaches and awareness programs.
