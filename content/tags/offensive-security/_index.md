Offensive security is a proactive approach to protect organizations and individuals from cyber attacks. It involves using the same tools, tactics, and techniques as an attacker when targeting an organization. Offensive security is focused on finding vulnerabilities and weaknesses in systems and networks through simulated attacks.

The following articles provide means of testing [organizational defenses]({{< ref "/tags/defensive-security/" >}} "Defensive Cyber Security") and identifying security gaps.
