These entries cover the access questions behind the [Agentic Identity Broker]({{< ref "/projects/agentic-identity-broker" >}}), which Magnus Jungsbluth and I built for agents that act on behalf of people. Each one explains what the relevant IETF and Model Context Protocol (MCP) specifications actually require and where our broker design fits. The MCP specification still changes between revisions, so the MCP entry names the revision it describes.
